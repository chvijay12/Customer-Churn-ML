ℹ️ About ChurnAI

Customer Churn Prediction System

🤖

ChurnAI

ChurnAI is a machine learning based customer churn prediction system.

The system analyzes customer information and predicts whether a customer is likely to leave the service.

It also provides a churn probability so that businesses can identify customers who may need additional attention.

🛠️ Technologies Used

Python Programming
Flask Web Backend
Scikit-learn Machine Learning
Pandas Data Processing
HTML Frontend
CSS Web Design

🧠 Machine Learning Model

Algorithm Logistic Regression
Accuracy 80.70%
ROC-AUC 84.18%
Dataset 7,043 Customers

🔄 How ChurnAI Works

1

Customer information is entered through the website.

2

The information is converted into machine-learning features.

3

The saved scaler prepares the data for the model.

4

Logistic Regression predicts customer churn.

5

The website displays the prediction and churn probability.
